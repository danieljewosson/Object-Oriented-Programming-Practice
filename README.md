# MyClass — Deep Copy, Copy Constructor & Assignment Operator

An educational C++ project demonstrating working with class objects, dynamic memory, copy constructors, assignment operators, deep copying, chained assignment, and self-assignment.

# What the Project Demonstrates


a regular constructor;

a destructor;

a copy constructor;

deep copying;

overloading the '=' operator;

chained assignment 'e = d = c';

self-assignment 'd = d';

working with dynamic memory.
